# ✂️ آکادمی آرایشگری مردانه — از صفر تا استادی

وب‌اپلیکیشن آموزشی کامل و رایگان برای یادگیری **آرایشگری مردانه به زبان فارسی** — مو به مو، مرحله‌به‌مرحله و با جزئیات کامل.

## ✨ امکانات

- 📚 **۹ فصل و ۳۷ درس کامل** با آموزش گام‌به‌گام
- 🪒 **مسترکلاس فید**: لو فید، مید فید، های فید، اسکین فید، تیپر، برست فید و دراپ فید — هرکدام با نقشه ارتفاع اختصاصی (SVG)
- 👑 **کوتاهی‌های کلاسیک**: بازز، کرو کات، آیوی لیگ، سایدپارت، پامپادور، فلتاپ، سیزر
- 💇 **سبک‌های مدرن**: تکستچد کراپ، فرنچ کراپ، کویف، آندرکات، کامب‌اور، مولت، ولف کات، مرلین
- 🇮🇷 **سنتی و کوچه‌بازاری**: خوردگی قیچی‌ای، دوکوپ، چتری محلی، اصلاح سنتی با تیغ و آتش‌گیری
- 🧔 **ریش و خط ریش**: فرم‌دهی، فید ریش، ریش بلند و مراقبت
- 💼 **کسب‌وکار**: اشتباهات رایج، مشتری‌داری، قیمت‌گذاری و برنامه تمرین ۳۰ روزه
- 🔍 **جستجوی هوشمند** در تمام متن درس‌ها (Ctrl + K)
- ✅ **پیگیری پیشرفت یادگیری** با ذخیره‌سازی محلی (بدون نیاز به ورود)
- 🔖 **نشانک‌گذاری درس‌ها** و ادامه یادگیری از آخرین درس
- 🌙 **تم تیره آرایشگاهی طلایی** با فونت وزیرمتن و طراحی راست‌چین (RTL)
- 📱 **کاملاً واکنش‌گرا** — روی موبایل مثل اپلیکیشن (قابل نصب به‌صورت PWA از منوی مرورگر «Add to Home Screen»)

## 🛠 تکنولوژی

| بخش | تکنولوژی |
|------|-----------|
| فریم‌ورک | Next.js 16 (App Router) + TypeScript |
| استایل | Tailwind CSS 4 + shadcn/ui |
| انیمیشن | Framer Motion |
| فونت | Vazirmatn (محلی) |
| ذخیره‌سازی | localStorage (بدون بک‌اند) |

## 🚀 اجرا

```bash
bun install
bun run dev
```

سپس `http://localhost:3000` را باز کنید.

## 📁 ساختار

```
src/
├── app/              # صفحه اصلی و استایل سراسری
├── components/barber # کامپوننت‌های رابط کاربری (خانه، فصل، درس، جستجو)
├── data/             # محتوای آموزشی (۹ فصل در data/modules)
└── lib/progress.ts   # ذخیره‌سازی پیشرفت یادگیری
public/fonts/         # فونت وزیرمتن
```

## 📝 مجوز

محتوای آموزشی و کد برای استفاده آزاد است. فونت وزیرمتن تحت مجوز SIL OFL منتشر می‌شود.
